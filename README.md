## About

Jam Is A New License For Small Projects

## What Jam License Protects

- ✅ Prevents selling your code without your permission
- ✅ Prevents others from claiming they wrote your code
- ✅ Requires your permission for code modifications
- ✅ License modification allowed under 4 conditions
- ✅ Breaking rules = permanent loss of license rights

## Files

- `LICENSE` — The full Jam License text (V:1.00)
- `JAM_DOCUMENTATION.md` — Version history and about section

## Usage

1. Copy the `LICENSE` file into your project root
2. Keep the license text unchanged (except for your name and year)
3. Share your project freely — but remember the rules!
